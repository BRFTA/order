# BRFTA Order v1
다중배송 주문 시스템 1차 프론트엔드 테스트 버전입니다.

현재: 주문자/수령인 입력, 배송지 추가·삭제, 전화번호 형식, 4개 상품 수량 0~9, 필수항목 검증, 주문 확인/수정, 모바일 대응.
다음 단계: 실제 주소검색, DB 저장, 관리자 로그인/주문관리, 신규주문 알림, 로젠택배 Excel.


v1.1 수정: 필수 오류 항목만 개별 강조, 상세주소 선택항목은 오류 강조 제외, 주소 검색 버튼 확대.

v1.2 수정: 도라지배즙/배즙에 사전 협의 주문 및 미협의 주문 출고 불가 안내문을 추가.

v1.3 수정: 첫 오류 이후의 필수항목도 모두 검증/강조되도록 오류 표시 로직 수정. 주문자·수령인 휴대전화번호 포함 모든 누락 항목을 동시에 표시.

v1.4 수정: 검증 함수를 전체 교체하여 주문자/수령인 전화번호를 포함한 모든 필수 입력칸이 동시에 오류 강조되도록 수정.

v1.5 수정: 필수 입력 오류 시 input 자체에 field-invalid 클래스를 적용하여 주문자/수령인 이름과 휴대전화번호가 확실히 빨간 테두리로 표시되도록 수정.

v1.6 수정: 테스트용 주소 직접입력(prompt)을 제거하고 Daum 우편번호 서비스를 연결. 주소 검색 결과 선택 시 우편번호+기본주소 자동입력, 상세주소는 선택 입력으로 유지.
