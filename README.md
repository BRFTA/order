# BRFTA Order v1
다중배송 주문 시스템 1차 프론트엔드 테스트 버전입니다.

현재: 주문자/수령인 입력, 배송지 추가·삭제, 전화번호 형식, 4개 상품 수량 0~9, 필수항목 검증, 주문 확인/수정, 모바일 대응.
다음 단계: 실제 주소검색, DB 저장, 관리자 로그인/주문관리, 신규주문 알림, 로젠택배 Excel.


v1.1 수정: 필수 오류 항목만 개별 강조, 상세주소 선택항목은 오류 강조 제외, 주소 검색 버튼 확대.

v1.2 수정: 도라지배즙/배즙에 사전 협의 주문 및 미협의 주문 출고 불가 안내문을 추가.
